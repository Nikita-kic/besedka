# Беседка

Тема WordPress + WooCommerce для интернет-магазина товаров для самогоноварения.

Собрана на основе структуры темы «Цвети» (методология БЭМ, чистый HTML/CSS/PHP/JS,
без CSS-фреймворков), переоформлена под бренд BESEDKA: новый логотип, категории
(Уголь, Дубовые кубики, Эссенции, Спиртовые дрожжи, Комплектующие, Бонификаторы)
и фирменный акцентный цвет.

Тестовые товары в каталоге — плейсхолдеры, замените на реальные позиции.
